
# FocusFlow

A clean, responsive task planner that helps you organize your day and stay focused.

## Features

- Add and delete tasks
- Set task priorities: High, Medium, Low
- Set due dates
- Mark tasks as completed
- View all, today's, upcoming, and completed tasks
- Search and sort tasks
- Track your task completion progress
- Automatically saves tasks in your browser using localStorage
- Responsive design for mobile and desktop

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

Open `index.html` in your browser, or visit the live GitHub Pages website.

## Data Storage

Tasks are saved locally in your browser. They are not synced between devices.
